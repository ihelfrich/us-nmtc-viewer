\section{Reproducibility}\label{app:repro}

Every number in this draft regenerates from the public repository:
\texttt{scripts/describe\_nmtc.py} builds the analysis files from the raw
CDFI workbook (hashes in \texttt{PROVENANCE.md});
\texttt{scripts/run\_regressions.py} produces Table~\ref{tab:main} and the
bunching statistics; \texttt{scripts/run\_robustness.py} produces
Table~\ref{tab:robust}; \texttt{scripts/make\_paper\_tables.py} writes the
table fragments included here. The repository also serves a browser-based
viewer with the full project map and specification explorer.
