\section{Reproducibility}\label{app:repro}

The public repository regenerates every number in this draft.
\path{scripts/describe_nmtc.py} builds the analysis files from the raw
CDFI workbook, with hashes recorded in \texttt{PROVENANCE.md}.
\path{scripts/run_regressions.py} produces Table~\ref{tab:main} and the
bunching statistics; \path{scripts/run_robustness.py} produces
Table~\ref{tab:robust}. \path{scripts/make_paper_tables.py} writes the
table fragments, and \path{scripts/make_paper_figures.py} renders the
figures included here. The repository also serves a browser-based viewer
with the full project map and specification explorer.
